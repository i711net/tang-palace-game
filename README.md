# 凤阙长安

一个静态网页宫斗选择游戏原型。打开 `index.html` 即可本地游玩。

## 玩法

- 开局输入玩家姓名。
- 每章至少 5 个独立事件，围绕当前品级所处环境展开。
- 章分达到晋升线才会升品级，并在章末自动存档。
- 选错关键选项会直接进入死亡、冷宫或失势结局。
- 前章选择会埋下伏笔：宫女、内侍、证物、上级信任，都可能在后章救命或反噬。
- 选项不显示提示，结果需要玩家自己判断和复盘。
- 剧情按地点自动切换背景图，当前说话人物会显示对应画像。
- 音乐由浏览器 Web Audio 生成，点击“乐声：关/开”即可切换。

## 章节

1. 朱雀门：验身、通铺、外信、浣衣与入宫问答，升为掖庭宫女。
2. 掖庭：针线陷害、绣带搜身、井边口供、夜里栽赃与名册封存，升为司籍女史。
3. 尚食局：莲子羹、药柜、替罪、灶间起火与赏赐选择，升为才人。
4. 蓬莱殿：妃嫔试问、披帛忌色、换酒、诗句、外信和禁军文书，升为婕妤。
5. 含元殿：召对、旧证、证人、对质、禁军笔迹与第一道懿旨，可走皇后线、女官执令线或贵妃同盟线。

## 美术资产

- `assets/scenes/`：朱雀门、掖庭、尚食局、蓬莱殿、紫宸殿、含元殿背景。
- `assets/portraits/`：皇后、贵妃、淑妃、郑昭仪、皇帝、高内侍、薛将军、云娘、锦儿、阿蘅、素荷、女官画像。

## 上线

这是纯静态站，不需要后端也能上线。可以直接放到 GitHub Pages、Cloudflare Pages 或 Vercel。
