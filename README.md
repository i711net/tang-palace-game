# 凤阙长安

一个静态网页宫斗选择游戏原型。打开 `index.html` 即可本地游玩。

## 玩法

- 开局输入玩家姓名。
- 每章至少 10 个独立事件题，围绕当前品级所处环境展开。
- 每题 4 个选项，页面显示 `1.` `2.` `3.` `4.`，选项顺序会按玩家名和题目稳定打乱。
- 章分达到晋升线才会升品级，并在章末自动存档。
- 选错关键选项会直接进入死亡、冷宫或失势结局。
- 前章选择会埋下伏笔：宫女、内侍、证物、上级信任，都可能在后章救命或反噬。
- 后章题干和选项会根据前章伏笔动态变化：有些看似送命的选择，只有提前救过人、登记过证物或取得信任，才会出现反转。
- 部分选项只有满足前置关系才会显示；未铺线时会换成普通保守选项。
- 选项不显示提示，结果需要玩家自己判断和复盘。
- 剧情按地点自动切换背景图，当前说话人物会显示对应画像。
- 音乐由浏览器 Web Audio 生成，点击“乐声：关/开”即可切换。

## 章节

1. 朱雀门：验身、名籍、通铺、分粥、外信、木牌、浣衣、值房问答等，升为掖庭宫女。
2. 掖庭：梳篦栽赃、金线陷害、药包、绣带搜身、灯油、井边口供、印泥、夜里香囊与名册封存，升为司籍女史。
3. 尚食局：御膳名单、药柜、催膳、托盘银匙、替罪、灶间起火、取药牌、安神茶与赏赐选择，升为才人。
4. 蓬莱殿：妃嫔试问、座次、披帛忌色、赏赐香囊、换酒、乐工旧曲、诗句、玉佩、外信、金耳坠和禁军文书，升为婕妤。
5. 含元殿：召对、旧证、云娘作证、素荷取药牌、阿蘅旧案、对质、动机反咬、禁军笔迹、空白懿旨与终局选择，可走皇后线、女官执令线或贵妃同盟线。

## 美术资产

- `assets/scenes/`：朱雀门、掖庭、尚食局、蓬莱殿、紫宸殿、含元殿背景。
- `assets/portraits/`：皇后、贵妃、淑妃、郑昭仪、皇帝、高内侍、薛将军、云娘、锦儿、阿蘅、素荷、女官画像。

## 上线

这是纯静态站，不需要后端也能上线。可以直接放到 GitHub Pages、Cloudflare Pages 或 Vercel。
